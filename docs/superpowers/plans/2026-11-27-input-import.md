# IMPORT 实施与验证

三项工作均已完成。54 项 Rust 测试、格式检查、Clippy 和 Minecraft 26.3 独立单人游戏完整回归通过。已安装的 MCP 与发行版构建产物哈希一致。

按[导入规格](../specs/2026-11-27-input-import-design.md)验证以下三个环节。

1. 在 Rust 解析器与加载器分别处理源文件的声明和整次提交的名字绑定。用文件测试验证两类入口、相对路径、共享依赖、循环及重名的来源和行号。
2. 编译时收齐库入口和所有函数引用的按键以供 Mod 校验，保留源文件与行号用于错误报告。协议只传根入口的可执行输入及提交内函数表。用单元测试核对未执行的库指令及实际发出的按键表。
3. 在 `tests/game/` 通过 stdio MCP 验证库入口直接运行与被导入时的区别、无效库键名和旧队列的原子性，以及暂停后修改库文件。同步脚本参考，经独立审阅和完整回归后更新本机 MCP。

实机用例核对了两份同名定义的文件与行号，以及未执行的库入口中错误键名的位置。两种错误都保留了旧队列和已按住的键。暂停期间修改同一库，两次调用分别派发了旧版 J 与新版 K。独立复核还覆盖了无写端的命名管道和字符设备，加载端会立即返回文件类型错误，随后提交仍可正常处理。见[导入实机用例](../../../tests/game/imports.py)。
