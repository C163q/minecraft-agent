# 暂停、手动继续与增量队列

PAUSE 是零拍控制指令，可独占一行或放在输入行末尾。先处理整拍再停；物理或脚本暂停键仅在按下边沿切换一次。暂停保留尚未执行的所有块、正在进行的鼠标移动和保持状态，完成普通 END 同样的服务端确认和停止帧。BEGIN 表达逻辑继续，无需释放已经按住的快捷键。

提交时整块先校验，再从旧队列下一拍叠加。每个块按自己的行序推进，旧到新合并同一拍的键和按钮指令，同名取最新声明；鼠标移动共同生效。等待表示本块无新增输入。旧块仍可显式 PAUSE，旧块 END 只结束该块。本次提交的 END 暂停全部。CLEAR 为零拍，清除更旧的待定输入和已有鼠标余量，保留已经显式保持的键与按钮。

手动继续中断的脚本时，继续原块，直到再次遇到暂停点或其 END。手动继续一个已经到达 END 的段时，世界持续运行，推进仍有的输入、移动及临时按键释放。玩家可以再按暂停键，模型也可以提交新块。快捷键应出现在原版按键设置里。

inspect_input 保留既有快照字段并报告停止原因。队列按紧凑的段表示，带块来源、源行号和剩余等待拍数。默认短预览，inline 可分页，游标绑定快照；file 原子写入调用方指定的文件并返回摘要。ON 另行设计。
