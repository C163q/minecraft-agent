# input_script 的时间与键盘输入

本阶段已确定普通输入块的逐拍时间模型、行首等待、临时按住与显式按住的交接，以及脚本文本和文件两种来源。用户与 LLM 查阅[脚本语法参考](../../input-script/README.md)；Rust 接入方式见[开发文档](../../development/README.md#rust-脚本库)。

## 设计依据

以客户端输入 tick 为单位，同一拍可以描述组合键。等待表达连续空增量，省去手工计数的多行空白。执行器比较连续两拍最终的按住状态，使保持方式切换时游戏收到连续的按住输入。[逐拍输入实测](../../research/2026-11-21-keyboard-tick.md)

把段尾与下一个输入 tick 分开，允许暂停时查询并在后续提交中继续操作。鼠标缓冲已有[跨暂停续跑与清除的实测](../../research/2026-11-21-buffered-mouse.md)，其文本表达式及事件监听留待后续设计。
