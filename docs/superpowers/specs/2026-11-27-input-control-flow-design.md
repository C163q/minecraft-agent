# 输入脚本的条件与循环

本规格适用于已有[变量、表达式与函数返回值](../../input-script/values.md)的输入脚本。条件选择、迭代、跳出和进入作用域都占零个输入拍。以下示例按 W 和 A 各一拍，顶层返回 5。

```text
BEGIN
    LET $keys = ["w", null, "a", "stop", "d"]
    FOR $key IN $keys
    BEGIN
        IF ($key == null)
        BEGIN
            CONTINUE
        END

        ELIF ($key == "stop")
        BEGIN
            BREAK
        END
        Key($key)
    END
    RETURN Len($keys)
END
```

## 条件与比较

`IF (表达式)`、`ELIF (表达式)`、`WHILE (表达式)` 要求布尔结果。`!` 是布尔取反；`!0` 为类型错误。两个值的类型不同时，`==` 得到 false，`!=` 得到 true。数字比较实际数值，`1 == 1.0` 为真；`1 == "1"` 与 `false == 0` 均为假。数组按相同下标递归比较，对象按同一组字段名和对应值递归比较。字符串比较区分大小写。大小比较 `<`、`<=`、`>`、`>=` 只接受数字，沿用现有数值精度。`Len(x)` 接受数组或对象，分别返回元素数或字段数；空集合返回 0。

运算优先级从高到低为成员与下标、一元 `!` 与负号、乘除、加减、大小比较、相等比较。例如 `$n + 1 >= $target` 先加后比，`!($n < 3)` 对比较结果取反。同优先级二元运算按从左到右结合；`1 < 2 < 3` 的第二次比较遇到布尔值会报错。

整次提交校验所有分支、函数及导入库，沿用[错误处理规则](../../input-script/values.md#工具结果和错误)。因此未命中分支里的 `!0` 也会在恢复前被拒绝。变量相关的判断只在实际执行到该条件时求值。

## IF、ELIF 与 ELSE

一条链由一个 IF、零个或多个 ELIF 和可选的末尾 ELSE 组成，每个分支体用独占行的 BEGIN 和 END 包围。按顺序只执行第一个命中的分支。全部为假且没有 ELSE 时直接继续。分支头与 BEGIN、ELSE 及循环跳转均按独立语句解析。

分支 END 后如接同一链的 ELIF 或 ELSE，中间任意空行、纯空白行和注释均占零拍。前瞻若未找到后续分支，应保留空行原有的每行一拍语义。块体内部的空行也照常占拍。ELSE 之后再写 ELIF、多个 ELSE、孤立 ELSE 或 ELIF 在提交时报告源行。

## WHILE、FOR 与跳转

WHILE 在每轮开始前重新判断条件。在循环体内暂停会保留当前位置，恢复后跑完本轮再判断。FOR 写作 `FOR $item IN 表达式`。进入循环时对表达式求值一次。数组按快照中的元素值及下标顺序迭代，对象按快照中的字段名按字典序迭代。循环体显式读取 `$obj[$field]` 时取该对象当时的值。其他类型不能遍历。字典序按 Unicode 码点升序排列，不依赖游戏语言或系统区域设置。

每个选中分支和每轮迭代都新建词法作用域，局部变量遵循 LET 的声明与遮蔽规则。FOR 循环变量作为本轮的普通局部绑定，迭代体内可以 SET 它。修改只影响本轮，不能借此改写迭代快照或原集合。

BREAK 跳到最近一层循环之后；CONTINUE 结束本轮，对 WHILE 重新判断，对 FOR 取下一项。两者在 IF 内可指向包围这个 IF 的循环。每次函数调用及每个事件处理块各自划定可跳转范围，缺少合法目标在提交前报错。函数深度只数实际的函数调用。

## 监听、返回与暂停

ON 从执行到声明时才注册，生命周期与同一作用域的局部变量相同。离开分支或迭代体时注销其监听并取消该作用域下尚未派发的处理动作。自然退出、BREAK 和 CONTINUE 都要执行相应的作用域清理。外层声明的监听在内层执行期间继续有效。沿用现有处理块内直接嵌套 ON 的限制，在处理块里增加一层分支或循环仍受同一规则约束。

作用域的最后一拍也可触发事件。按既有时序先处理该边界已观察到的通知，同一批按注册顺序执行零拍指令。沿用现有函数监听的拍末顺序。处理块执行 PAUSE 后，注册者在同一边界的普通零拍指令仍可执行；会销毁该监听现场的作用域退出（包括 BREAK、CONTINUE 或 RETURN 所需的退出）推迟到恢复。例如分支中 Wait(1) 后紧跟 Print("owner") 和分支 END，该拍恰好有监听执行 PAUSE，则本次停止结果包含 owner 这一行，分支仍保留至恢复。同批较晚处理的监听若要通过 RETURN 退出注册者，并因此销毁这个已暂停的分支或迭代作用域，也要在恢复后才求返回值。普通分支或迭代体的 END 只离开局部作用域。处理块自身的 END、CLEAR、顶层 END 和手动恢复保留[原有停止语义](../../input-script/events.md#生效时序)。

RETURN 仍归注册者所在的函数调用或顶层提交。即便 ON 声明在 FOR 内，处理块里的 RETURN 也可退出注册者的整次函数调用；处理块调用的辅助函数里的 RETURN 仍返回给该处理块。脚本 PAUSE、上限暂停或快捷键暂停后，保留已选分支、当前迭代、快照、局部变量和未执行输入。恢复同一次执行不会重复求值之前已经选中的条件或重新启动 FOR。

## 连续零拍执行额度

同一份提交及其处理块共享一个计数器。每进入一次函数或进入一轮循环体计 1；条件为假的 WHILE、空集合的 FOR、IF、BREAK、CONTINUE 自身均不计。允许第 4096 次进入，尝试第 4097 次时在执行该函数或本轮循环体前报错，定位到调用点或循环头。已产生的 stdout 仍随错误交付，出错提交终止，其他提交暂停。

同一边界内暂停再恢复时保留计数，新提交使用自己的计数器。实际推进一个输入拍后开启新额度。`WHILE (true)` 的循环体只有 CONTINUE 时触发零拍保护；每轮都执行 Wait(1) 时受[单次调用拍数上限](../../input-script/pause.md#限制单次调用的拍数)约束。

## 实施与验收依据

Rust 解析结构、绑定词法名、检查循环跳转目标并保留源行。Mod 在已有队列内保存执行位置和作用域，并在客户端输入边界决定下一步。静态展开无法表达监听改变 WHILE 条件、F8 恢复或多份输入叠加后的执行顺序。队列预览沿用函数调用的呈现方式。尚未进入的结构以控制头的源行表示，暂停在结构内时展示已选分支或本轮余下工作，未来的迭代保留为循环头。读取预览不求值、不进入分支，也不消耗执行额度。

验收覆盖示例的实际两拍、未选分支跳过动态错误、分支间与链后空行计拍、对象键序与集合快照、暂停恢复、嵌套跳转、末拍监听、外层 RETURN 和新旧提交隔离。纯零拍测试须覆盖空循环、恰好 4096 次、跨函数及监听超额、同拍暂停后续算、经过一拍后额度刷新。实机核对实际派发、服务端暂停以及 MCP 的停止原因、源行和已打印内容。
