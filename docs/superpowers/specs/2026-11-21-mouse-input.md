# 鼠标输入与截图瞄准

目标是在现有本地单人键盘与 END 截图通路中加入鼠标。模型能在 GUI 依图点选并拖动，在第一人称依图选方向，并在独立调用之间继续尚未走完的移动。

MouseMove 与 MouseMoveTo 分别表示相对位移与 GUI 绝对坐标。后者在生效时根据光标位置一次性转换成相对位移。位移及速度支持 Px、Percentage 和 Rotate，分别表示像素、对应窗口轴的百分比、按当时鼠标设置折算的角度。两个参数默认沿目标方向使用配置的最大速度；附一个速度沿直线，附两个速度按轴推进。每拍先求所有当拍位移的向量和，按合速度上限同比例扣减各项余量，相互抵消的部分也算完成。默认上限 50 px/tick。

WaitMouseMove() 只等待移动，空闲时占零拍。END 冻结余量，下次恢复后继续。Mouse、MousePress、MouseRelease 使用 left、right、middle，保持、交接、冲突规则与键盘一致。每拍先移动再派发鼠标按钮。采用显式等待，保证移动期间可以截图、按住或释放按钮。取消或离开世界清理脚本输入状态。

cursor_hint 在图片副本上标红点，支持按原图像素或百分比选点。默认请求相对转角，可用 include_rotation 关闭。第一人称游戏截图绑定当帧的相机数据，返回向右、向下为正的水平与垂直角差。普通图片和 GUI 可正常标点，请求角度时给出不可用原因。执行旋转仍通过 MouseMove。历史探针提供[分拍移动](../../research/2026-11-21-buffered-mouse.md)、[GUI 点击](../../research/2026-11-21-codex-gui-click.md)与[第一人称输入](../../research/2026-11-21-first-person-mining.md)的独立基线。
