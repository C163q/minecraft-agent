# Codex 第一人称瞄准与持续挖掘

2026-11-21，在 Minecraft Java Edition 26.3、Fabric Loader 0.20.1 的独立单人生存世界中验证相对鼠标输入和连续挖掘。使用 Codex CLI 和 `gpt-6.2-astra`。玩家空手站在平地，视野正前方有一个悬空泥土方块和一个青金石块，左右位置随机。模型只能通过 Rust stdio MCP 的 `input_script` 观察和操作，工具结果含世界暂停状态及游戏原生截图。服务端目标位置、准星命中记录、实际转角和方块状态仅用于验收。

## 输入与验收方法

- 每个灵敏度先输入相同的相对移动：水平向右 48 个鼠标输入单位，分四个客户端输入 tick 完成，再向左 48 单位回到初始朝向。灵敏度为游戏设置的内部数值。测量原版实际处理输入后的偏航角，此处的鼠标单位不能直接解释为截图像素。
- 盲测开始后由模型选择 `Move(dx,dy)` 的方向与距离。探针在鼠标已被游戏捕获的情况下通过 `MouseHandler.onMove` 注入相对位移，经原版 `handleAccumulatedMovement` 处理，每拍合位移上限为 12 个输入单位。
- 模型必须先观察转动后的帧再提交 `HoldLeft(n)`。探针在第一拍按下左键，保持 n 拍并逐拍读取攻击键状态，第 n+1 拍释放。由原版生存模式处理射线命中、挖掘进度和方块破坏。
- 到 END 等待服务端暂停，通过原版方块更新包同步这两个测试位置，在同连接请求标记后渲染和读回截图。模型根据图像报告泥土是否消失、蓝色方块是否保留。独立检查最后一帧时的服务端方块状态、世界暂停状态、鼠标和攻击键释放状态，并校验 Codex 收到的各帧与游戏 PNG 字节一致。

## 实测结果

| 灵敏度 | 同样向右 48 单位的转角 | 模型依次提交的瞄准输入 | 实测按住左键 | 模型收到的图片 |
| --- | ---: | --- | ---: | ---: |
| 0.35 | 3.96985° | `Move(125,8)` | 25 拍，第 26 拍释放 | 3 张 |
| 0.75 | 15.81840° | `Move(-120,12)`、`Move(56,-3)` | 22 拍，第 23 拍释放 | 5 张 |

较高灵敏度下，模型首次向左转动 39.55°，观察后向右修正 18.45°，再次看图后才开始挖。两轮按下瞬间的游戏射线都命中了泥土，攻击键分别持续生效 25 和 22 拍，各只有一次按下和一次释放。两轮在挖掘后的第一张停止图对应时刻都已由服务端确认泥土原位置为空气、青金石块完好。第二轮中模型额外提交了 `Wait(30)` 再作最终判断。两次模型判断与服务端记录一致，结束时攻击键和鼠标左键均已松开。

该结果覆盖两种设置下的静止玩家、固定且可触及的方块和空手生存挖掘。25 和 22 是模型选择并实际保持的时长；本次没有测量破坏泥土所需的最短时长。相对输入经过原版灵敏度换算，`Move`、`HoldLeft` 和 `Wait` 均为探针指令，正式脚本语法仍待确定。

## 本机复核

探针代码和证据位于工作区的 `.tmp/mine/`。在该目录执行 `python3 check.py low` 和 `python3 check.py high` 可对照模型操作、各帧 PNG、准星命中、按键和世界状态。两个子目录各自的 `ipc/` 保存按提交顺序编号的停止图。实测由游戏自带的鼠标事件处理入口开始，未测试物理设备或桌面级鼠标注入。
