# 鼠标移动、等待与按钮

在箱子、背包或菜单中，光标的位置以游戏原始截图左上角为原点，向右和向下为正。在第一人称中，鼠标被游戏捕获，相对鼠标输入会转动视角。操作时保持游戏窗口获得焦点。根据第一人称截图瞄准的示例见[截图标点](cursor-hint.md)。

## 位置和速度

| 写法 | 行为 |
| --- | --- |
| `MouseMove(x, y)` | 从本拍开始走相对位移，沿目标方向以配置的最大合速度移动 |
| `MouseMoveTo(x, y)` | 光标可自由移动时使用。在本拍开始时，用目标位置减去当时的光标位置，随后按相对移动执行 |
| `MouseMove(x, y, speed)` | 以给定合速度沿直线推进；末拍只走剩余距离 |
| `MouseMove(x, y, sx, sy)` | 两轴以各自的速度大小推进，方向由位移决定，先到达的轴先停止 |

`MouseMoveTo` 也接受同样的第三、第四个参数。每个参数都要写单位，数值可以是有限小数。速度按输入 tick 计算。单个速度须大于零；某轴位移为零时，该轴的速度也可以为零。

| 单位 | 含义 |
| --- | --- |
| `Px(n)` | GUI 中以原始截图像素计。鼠标被捕获时表示相对鼠标输入单位，实际转角取决于灵敏度 |
| `Percentage(n)` | X 按帧宽、Y 按帧高的 n% 换算，负数表示相反方向。作为单个合速度时，沿运动方向按窗口两个轴的比例换算 |
| `Rotate(n)` | 以度计，X 向右、Y 向下为正。按激活时的灵敏度、轴反转和望远镜状态折算鼠标输入量；在 GUI 中使用同一次换算来移动光标。第一人称使用该单位需关闭平滑电影视角 |

例如 `MouseMove(Px(30), Px(40), Px(10))` 每拍走 (6, 8)，共五拍。若指定两个速度 `Px(10), Px(10)`，前三拍各走 (10, 10)，第四拍走 (0, 10)。以上均假设没有其他移动且全局限速为默认值 50。GUI 光标碰到窗口边缘时停在边缘。

## 并发、等待与段尾

一条移动指令占一拍，首步在这一拍生效，后续输入与未完成的移动可以同时进行。同一拍可启动多条移动。每拍先合计各移动请求的位移向量。合位移长度超过上限时，所有请求按同一比例缩短，并从各自余量扣除本拍实际分摊部分。反向抵消的部分也算完成。比如同时请求向右 80、向左 40，合位移为向右 40；在上限 50 时，两项本拍请求都完成。

`WaitMouseMove()` 等待所有进行中的移动完成。已经空闲时占零拍；若最后一步在第 4 拍完成，后面的普通输入在第 5 拍执行。可独占一行，也可放在行首，与其后的输入同写一行。已按住的按钮在等待期间仍遵循下面的按钮规则。

`END` 保留移动余量，下一次提交的输入拍可继续推进。独占一行的 `CLEAR` 在当前位置消耗零拍，清除当前的移动余量。例如下面两次提交分别执行一拍和三拍，位移依次为 50、50、50、10。

```text
BEGIN
MouseMove(Px(160), Px(0), Px(80))
END
```

```text
BEGIN
WaitMouseMove()
END
```

## 点击、长按与拖动

按钮名为 `left`、`right`、`middle`。按键的持续、交接和同拍冲突规则与[键盘](keyboard.md)一致。同一拍先完成合成移动，再派发按钮事件。

| 写法 | 行为 |
| --- | --- |
| `Mouse(left)` | 本拍按住左键，相邻拍继续声明会保持；下一拍省略且无显式保持时松开 |
| `MousePress(left)` | 持续保持左键，包括跨段和等待期间 |
| `MouseRelease(left)` | 释放左键 |

下面的脚本从当前光标位置开始拖动，到达截图上的目标位置后松开。若需完成一次普通单击并在释放后观察，可用 `Mouse(left)` 接一行 `Wait(1)`。

```text
BEGIN
MousePress(left)
MouseMoveTo(Px(908), Px(365))
WaitMouseMove()
MouseRelease(left)
END
```
