# 变量、表达式与输出

变量名以 `$` 开头。用 `LET` 声明变量，用 `SET` 修改已声明的变量或其成员。每条赋值独占一行，赋值本身占零拍。模型可以用顶层 `RETURN` 取一个 JSON 值，用 `Print` 在同次工具结果中取执行日志。

```text
FUNCTION $step($key, $duration)
BEGIN
    KeyPress($key)
    Wait($duration)
    KeyRelease($key)
    RETURN $duration + 2
END
BEGIN
    LET $ticks = $step("w", 5)
    Print("walked for {} input ticks", $ticks)
    RETURN {ticks: $ticks, key: "w"}
END
```

本例走过七个输入拍。W 在第一拍按下，等待五拍，在第七拍松开。工具结果含 `"return_value":{"ticks":7,"key":"w"}` 和 `"stdout":"walked for 7 input ticks\n"`。

## 对象、数组和作用域

值可为 null、布尔值、数值、字符串、数组或对象。对象允许用标识符或双引号字符串作键。数组下标从 0 起算。带点号或连字符的字段名可用字符串下标读取，例如 `$target["block-id"]`。对象和数组内部可以换行及写整行注释，空行也不占拍。

```text
BEGIN
    LET $target = {
        id: "minecraft:stone",
        pos: [1, 2, 3]
    }
    LET $copy = $target
    SET $copy.pos[0] = 4
    RETURN [$target.pos[0], $copy.pos[0]]
END
```

返回 `[1,4]`。赋值、传参和返回都使用值语义。读取缺失字段或读取 null 的字段得到 null。读取其他非对象值的字段或访问越界数组下标会报错。写入对象末级字段可以增加字段；写数组元素须有有效下标。一次 `SET` 只写一个目标。

同一次函数调用、顶层入口、每次事件触发各有自己的局部变量。函数形参与函数体在同一作用域。监听可读取或修改注册位置可见的变量，取得执行时的当前值。内层可用 `LET` 遮蔽外层声明，同层重名会在提交前报错。`LET $x = $x` 先读取外层的值，再创建内层绑定。

暂停会保留变量和等待中的赋值，新提交有自己的变量空间。执行 `SET $items[$i] = $f()` 时，先确定下标并验证目标，再执行函数；函数返回时在当前数组中写该下标。期间对其他元素的修改会保留。

## 计算和输入参数

`+`、`-`、`*`、`/`、一元负号及括号支持通常的优先级。数值运算要求数值类型，`5 / 2` 得到 2.5。计算整数时保留精度，例如 `9007199254740992 + 1` 得到 9007199254740993。除不尽的十进制结果通常取 34 位有效数字；结果极接近整数时保留额外小数位，以便取整和等待时长检查。以下内置函数都不占拍，可以嵌套于表达式。

| 函数 | 例子 |
| --- | --- |
| `Floor(x)`、`Ceil(x)` | `Floor(-1.2)` 得到 -2，`Ceil(-1.2)` 得到 -1 |
| `Abs(x)` | `Abs(-4)` 得到 4 |
| `Min(a, b)`、`Max(a, b)` | `Max(1, Ceil(5 / 2))` 得到 3 |

`Wait(Floor(5 / 2))` 等两拍。等待参数须为正整数；在实际消费第一拍前求值，之后即使变量改变，已经开始的等待也只消耗剩余拍数。对于 `Wait($n) Key($key)`，键名在随后的按键拍求值。`Key($key)` 和 `Mouse($button)` 接受名称字符串，与原有的 `Key(w)`、`Mouse(right)` 共用键名与按钮规则。数字键 1 可以沿用原写法 `Key(1)`；用变量传入时，它的值必须是字符串 `"1"`。鼠标单位中可以计算数值，例如 `MouseMove(Rotate(-Abs($yaw)), Px(0))`。

动态输入会在派发这一拍前校验；涉及鼠标动作时，也按当时的窗口、光标和灵敏度完成换算。例如要在背包中执行带变量的 `MouseMoveTo`，先用一拍打开背包，再在下一拍移动光标。含动态输入的拍先在取样时的界面派发算好的鼠标位移，再派发键盘和鼠标按钮；同拍按 Esc 关闭背包时，这一步位移仍作用在背包光标上。

布尔取反、比较运算和 `Len` 的类型与优先级见[条件与表达式](control-flow.md#条件与表达式)。

## 函数与事件值

有参数的函数写作 `FUNCTION $name($a, $b)`，调用时给出数量相符的位置实参。独占一行的 `$name(...)` 会运行函数并丢弃结果。要使用结果，将函数调用写成 `LET` 或 `SET` 的整个右侧。自定义函数可以走过多个输入拍；暂停或达到 `max_ticks` 后继续原调用，返回时完成赋值。函数自然结束和函数内的裸 `RETURN` 都返回 null。有关提前退出哪次调用，见[函数、调用与返回](functions.md)。

所有事件都支持可选的只读参数，如 `ON(BlockInteracted($hit))`。它属于处理块，保存此次事件的快照，包括 `$hit.event` 和该事件的现场字段；可以将其复制到可修改的变量。以下函数在挖掉方块时返回实际注册名，超出等待时间则返回 null。

```text
FUNCTION $mine($timeout)
BEGIN
    ON(BlockBroken($hit))
    BEGIN
        RETURN $hit.id
    END
    MousePress(left)
    Wait($timeout)
    RETURN null
END
BEGIN
    LET $id = $mine(40)
    MouseRelease(left)
    RETURN $id
END
```

## 工具结果和错误

| 字段 | 出现时机 |
| --- | --- |
| `return_value` | 当前提交的顶层实际执行了带值的 `RETURN`，显式 null 也有字段。普通段尾、裸返回和中途暂停省略该字段。旧提交的返回值归旧提交。 |
| `stdout` | 本次工具调用期间有 `Print` 输出。包括旧块、函数及监听在此期间新打印的文本，每次打印追加一个换行。F8 单独续跑期间的输出不计入下一次请求。 |
| `script_error` | 执行时求值失败。与 `pause_reason: "error"`、`ticks`、已生成的输出和可选停止图一起返回，包含消息、块号、源行及调用栈。 |

`Print("pos={} tag={}", $pos, $name)` 独占一行，占零拍。`{}` 按顺序对应实参；`{{`、`}}` 输出字面花括号。字符串按原文打印，其余值输出紧凑 JSON。格式串中的 `$` 是普通字符。调用参数每项都成功求值后才会写入这行日志。单次调用累计最多输出 4,194,304 个 UTF-16 代码单元（含换行）；一行超过剩余空间时，返回运行时错误并保留此前的完整行。

名字、格式串、参数个数和纯常量表达式等在提交时校验。依赖运行时值的错误会终止整份出错的提交并暂停世界，其他提交保留。发生动态输入冲突时，该拍的键鼠动作都不派发。若同一边界的截图也失败，结果保留脚本错误和已打印文本，另用 `capture_error` 说明截图失败原因。已经生效的保持状态和移动余量可通过[查询当前输入状态](inspect.md)查看，再按需提交释放或清除指令。

单个表达式最多嵌套 48 层、含 4096 个节点。对象和数组复制时最多 48 层、16,384 个值节点。数值精度及小数位尺度的绝对值上限为 4096。超出限制会报告对应的源位置。
