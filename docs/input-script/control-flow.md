# 条件、循环与比较

用 `IF`、`ELIF`、`ELSE` 选择输入，用 `WHILE` 重复判断，用 `FOR … IN` 遍历数组或对象。每个结构头、`BEGIN`、`END` 各占一行。结构本身占零拍，输入仍按实际派发计拍。下面的脚本按 W 和 A 各一拍，返回数组长度 5。

```text
BEGIN
    LET $keys = ["w", null, "a", "stop", "d"]
    FOR $key IN $keys
    BEGIN
        IF ($key == null)
        BEGIN
            CONTINUE
        END

        ELIF ($key == "stop")
        BEGIN
            BREAK
        END
        Key($key)
    END
    RETURN Len($keys)
END
```

## 条件与表达式

`IF (条件)` 后可跟任意个 `ELIF (条件)` 和一个可选的 `ELSE`。按顺序判断，执行第一个命中的分支，然后从整条链之后继续。分支内暂停时，恢复后继续这个分支。运行时只求值实际到达的条件；提交前的语法、词法名和常量检查覆盖整条链。

| 写法 | 效果 |
| --- | --- |
| `!$flag` | 布尔取反。条件和取反都要求布尔值，判断数值是否为零写 `$n == 0` |
| `$a == $b`、`$a != $b` | 比较任意 JSON 值。不同类型不相等；数字按数值比较，`1 == 1.0` 为真，`1 == "1"` 为假 |
| `<`、`<=`、`>`、`>=` | 数字大小比较。区间判断需分别比较两端 |
| `Len($collection)` | 返回数组元素数或对象字段数。空集合为 0，数组中的 null 也占一个元素 |

数组按位置逐项比较；对象按字段名和对应的值递归比较，字段书写顺序不影响相等性。优先级从高到低为成员与下标、一元取反与负号、乘除、加减、大小比较、相等比较。`$n + 1 >= $target` 先算加法。要对比较结果取反，可以写 `!($n < 3)`。

上一支的 `END` 与同一条链的 `ELIF` 或 `ELSE` 之间，空行和注释都占零拍。整条链之后、普通指令之前的空行仍每行占一拍。选中分支体内的空行也照常计拍。

## 迭代与作用域

`WHILE ($remaining > 0)` 在开始每一轮之前重新求值。`FOR $item IN 表达式` 在进入循环时只求值一次。数组按快照中元素的先后顺序遍历；对象按字段名的 Unicode 码点升序遍历，循环变量得到字符串字段名。此时用 `$obj[$item]` 读取原对象，取得的是执行到该行时的字段值。向原对象添加字段不会增加本次的迭代次数。

每个选中分支、每轮迭代都有独立作用域。循环变量可以遮蔽外层名字，也可以用 `SET` 修改；修改只在本轮有效。`BREAK` 和 `CONTINUE` 各自独占一行。前者退出最近一层循环，后者结束当前轮，随后重新判断 WHILE 条件或取下一个 FOR 元素。条件、循环及 ON 声明的块体最多嵌套 30 层。函数和事件处理块各自划定跳转范围。事件中的 `RETURN` 仍可[退出注册监听的函数或顶层脚本](functions.md#哪些输入会继续执行)。

`PAUSE`、快捷键和 `max_ticks` 都会保留分支位置、迭代快照和当前局部值。`inspect_input` 预览实际等待执行的工作；未进入的结构及尚待继续的循环可用控制头的源行定位。

## 监听和同拍暂停

`ON` 执行到声明时注册。离开声明所在的分支或本轮迭代，会注销监听并取消该作用域下未派发的处理动作；要监听整个循环，把声明写在循环之前。处理块自身走到 `END` 时仍按[事件规则](events.md#生效时序)暂停，包括其中的 IF 没有选中任何分支的情况。

若监听在所属作用域最后一个输入拍观察到事件，这次事件仍然有效。例如，分支先注册一个只执行 `PAUSE` 的受伤监听，接着依次执行 `Wait(1)`、`Print("owner")` 和分支 `END`。假如这一拍末触发监听，本次停止的 `stdout` 包含 `owner\n`。注册者的打印属于同一边界，分支退出会推迟到恢复之后。同批靠后触发的监听如果执行 `RETURN` 会销毁这个已暂停的局部作用域，也会等到恢复后才计算返回值并退出。

## 零拍执行上限

同一提交的所有函数及事件处理块共享额度。在两个实际输入拍之间，每进入一次函数或一轮循环体计 1 次，最多 4096 次。第 4097 次在执行该轮或函数之前报错。空集合、条件为假的 WHILE 和 IF 本身不计数。`CONTINUE` 占零拍，因此仅执行 `CONTINUE` 的无限循环会触发此上限。

同拍暂停再恢复保留已用额度；实际走过一拍后刷新。循环体每轮都执行 `Wait(1)` 时，[单次调用的 max_ticks](pause.md#限制单次调用的拍数) 仍会按实际拍数交回控制。零拍超额按照[运行时错误规则](values.md#工具结果和错误)终止出错的提交，保留此前打印的内容并暂停其他提交。
