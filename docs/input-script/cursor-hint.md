# 根据截图标点与瞄准

`input_script` 默认返回停止帧的 PNG、原始宽高和 `screenshot_id`。`cursor_hint` 在原图的副本上标红点和红环，返回带标记的 PNG、原始图像尺寸与所选像素。标点期间游戏保持原状态。

| 参数 | 填法 |
| --- | --- |
| `screenshot_id` 或 `path` | 两者选一。前者来自同一 MCP 进程的停止帧；后者是 MCP 主机上的 PNG 文件，可使用相对于 MCP 工作目录的路径 |
| `x`、`y` | 原始 PNG 左上角为 (0, 0)。每轴可填零起算的整数像素或百分数字符串，如 `"25%"`。百分数范围 0% 到 100%，100% 指最后一个像素 |
| `include_rotation` | 可选，默认为 `true`。传 `false` 只取标点和坐标 |

例如模型在一张第一人称截图上看到了目标，调用时可以传：

```json
{"screenshot_id":"<input_script 返回的 ID>","x":"65%","y":"40%"}
```

若客户端显示的是缩略图，可使用百分比，或按结果中的原始宽高换算像素。先从标记图确认红点在目标上，再读文本结果中的 `rotation.yaw_delta_deg`（向右为正）和 `rotation.pitch_delta_deg`（向下为正）。假设取到 12.4 和 -3.1，可直接在下一次提交中使用：

```text
BEGIN
MouseMove(Rotate(12.4), Rotate(-3.1))
WaitMouseMove()
END
```

转角取自该截图的世界相机，表示拍摄时所选像素的方向。视角晃动时相机与玩家眼睛可能有位移，近处物体会有视差。若玩家或目标移动，可根据新的停止帧再次标点。GUI 截图、普通 PNG 和没有玩家第一人称相机数据的帧也可标点，默认返回 `rotation: null` 与 `rotation_unavailable`。关闭转角时省略这两个字段。

MCP 会话最多保存最近 8 张原图，按 64 MiB 的 PNG 缓存预算淘汰旧帧，至少保留最新一张。过期或来自其他进程的 ID 会报错；重新观察即可取得新的 ID。
