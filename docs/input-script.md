# input_script 脚本语法参考

本文供编写脚本的玩家和 LLM 按需查阅。当前 Rust 解析器支持普通输入块、等待和键盘操作。以下示例均从所有键已松开的状态开始。每一拍对应一个客户端输入 tick。

## 完整示例

```text
BEGIN
Key(w)
Key(w) Key(space)
Wait(2) Key(a)
END
```

第 1 拍按住 W。第 2 拍继续保持 W，同时按下空格。第 3 拍松开两键，第 4 拍仍为空输入，第 5 拍按住 A。整块共 5 拍。`END` 本身消耗 0 拍；下一次推进输入时，由下一拍决定 A 是否继续保持。

## 输入行和注释

每次提交一个由 `BEGIN` 和 `END` 包围的块，两者分别独占一行，可附行尾注释。普通按键行占一拍，同一行中的键在这一拍共同生效。空行或只有空格的行在块内也占一拍。

从原始行的第 1 列开始写 `//`，整行消耗 0 拍。如果 `//` 前面只有缩进，则去掉注释后留下一个空输入 tick。下面的块恰好占两拍：第一拍按住 W，第二拍松开。

```text
BEGIN
// Skip this comment line.
Key(w) // Press W for this tick.
  // One empty input tick.
END
```

## 等待与键盘

| 写法 | 占用拍数及效果 |
| --- | --- |
| `Wait(n)` | 展开为 n 拍空增量输入。独占一行的 `Wait(1)` 总共只占 1 拍 |
| `Wait(n) Key(w) Key(a)` | 前 n 拍为空输入，在第 n+1 拍同时按住 W 和 A |
| `Key(w)` | 本拍保持 W。相邻拍重复声明只产生一次按下；第一拍省略 W 时松开，除非 W 仍被显式保持 |
| `KeyPress(w)` | 从本拍起持续按住 W，经过空行和等待也保持 |
| `KeyRelease(w)` | 从本拍起松开显式保持的 W |

```text
BEGIN
Key(w)
KeyPress(w)
Wait(5)
KeyRelease(w)
END
```

第 1 拍按下 W，第 2 拍由显式保持接手，交接时不产生松开或重复按下。第 3 至 7 拍保持，第 8 拍释放。若省略第一行 `Key(w)`，则 W 恰好按住 6 拍，在第 7 拍释放。

## 脚本来源与当前支持范围

工具设计接受内联文本 `script` 或文件路径 `path`，每次选择一种。两种来源在 Rust 核心中共用同一解析器。脚本文件使用 UTF-8，保留空行和缩进，支持 LF 和 CRLF。使用文件时可传绝对路径；核心库将相对路径交给调用方指定的基准目录解析。正式 MCP 接入尚待实现。

指令名区分大小写。当前解析器接受由 ASCII 字母、数字和下划线组成的非空键名，按原样比较；具体键名与游戏物理键位的绑定属于后续接入工作。命令间用空白分隔，括号内直接写参数。

当前支持行首单个 `Wait`，参数为正的十进制整数（`u64` 范围）。零等待、行中或重复的 `Wait`、同一拍对同一键同时要求按下与释放，均返回行号错误，留待后续语法讨论。整块通过解析后才能产生输入。鼠标、清除和事件监听的文本写法仍未定稿。
